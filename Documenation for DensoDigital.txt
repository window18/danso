Установка зависимостей - npm install
Запуск проекта в DEV режиме - npm run dev
Запуск в продакш(сайт работает как обычный грузит быстрее страницы и т.д) - npm run build (создается папка .next с билдом). npm start (запускает сам билд)
Папка public - все svg, png, jpg...
Папка src - все компоненты и сами страницы
src/app - страницы
src/components/shared - переиспользованые компоненты
src/components/ui - компоненты кнопок инуптов и т.д (не трогать)
Папка shared - aside(Главная страница левая часть) + asidearchive, asideonline (пункт онлайн и архив). header (навигация сверху). headermodal (модальное окно пользователя). Layout and .... (не трогать. Это сами раскладки для камер). rightaside (вся правая часть главное страницы кнопки и часть раскладок).
Папка adminShared - asideCamera (компонент с таблицой камери и просто вся правая часть Администрации). header (навигация).
Папка adminShared/server - компоненты Администриования\Настройка сервера
Папка ui - компоненты shadcn..
Папка src/app... - страницы, название папок в app = url адрес
Папка корневая папка/lib - папка для логики. Например api.js (запрос к api), db.js (подключение к базе), auth.js (логика авторизации), utils.js (вспомогательные функции)
Папка корневая папка/data - локальные данные, data_camera.json (данные для самих камер в таблице администрации)
